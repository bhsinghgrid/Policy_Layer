🚫 DENY Branch

            
Immediate containment. Action blocked, security notice sent to agent observation without leaking system internals, logged to audit ledger.

          

          

            
🎫 ASK USER Branch

            
Generates cryptographic approval ticket. Pauses execution until authorized operator approves via UI. Revalidates snapshot hash (RV) before execution.

          

          

            
✅ ALLOW Branch

            
Forwards validated action to Controlled Executor. Adapters execute action and return structured result to agent and persistent audit state.
